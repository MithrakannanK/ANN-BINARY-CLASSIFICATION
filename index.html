🔬 Visual Inspection Gallery

Decision Boundary Analysis: Linear models like Logistic Regression are strictly constrained to a single straight line $\mathbf{w}^T\mathbf{x} + b = 0$, misclassifying the crescent tails. All three ANNs project features through non-linear ReLU activations to generate adaptive S-curve manifolds wrapping cleanly around the moons.

Loss & Accuracy Convergence: Tracks epoch-by-epoch learning. The NumPy ANN (using our custom Adam implementation) steadily minimizes Binary Cross-Entropy loss from 0.26 to 0.045, matching the PyTorch AdamW training trajectory.

Receiver Operating Characteristic: All neural networks attain near-perfect discriminative capability with AUC scores exceeding 0.992, compared to 0.9536 for the linear baseline.

Confusion Matrices: Demonstrates balanced True Positive and True Negative rates on 300 unseen test samples (150 per class) with minimal misclassification errors.

Dataset Structure: 1,500 samples generated with Scikit-learn's make_moons(noise=0.20). Gaussian noise creates realistic overlapping points across the decision boundary.

⚡ Theoretical Ceiling

With Gaussian noise $\sigma = 0.20$, roughly $3.3\%$ of points inherently cross over. The achieved 96.67% test accuracy reaches the Bayes Optimal decision limit.

🧠 Zero-Dependency Core

The NumPy implementation uses raw mathematical matrix multiplication, He weight initialization, and analytical chain-rule backpropagation without relying on external deep learning frameworks.

🚀 Framework Parity

PyTorch and Scikit-Learn achieve parity with our from-scratch NumPy model, validating the mathematical exactness of our custom forward and backward passes.
